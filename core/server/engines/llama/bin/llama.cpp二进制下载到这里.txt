llama.cpp 预编译动态库（GGUF 解码与 ForceAligner）

代码固定使用 llama.cpp b10621。必须将发行包中的动态库解压到本目录的 b10621/ 子目录；不要放在 bin/ 根目录。启动时会校验版本目录及 ggml、ggml-base、llama 三个库，目录缺失或库文件缺失会直接报错。其它后端动态库也请一并保留在同一目录，供 ggml_backend_load_all() 发现。

官方 release 下载地址格式：
https://github.com/ggml-org/llama.cpp/releases/download/b10621/<资产文件名>

已核实的资产与核心库文件名：
- macOS Apple Silicon (Metal)：llama-b10621-bin-macos-arm64.tar.gz
  - libggml.dylib、libggml-base.dylib、libllama.dylib
- Windows x64 Vulkan：llama-b10621-bin-win-vulkan-x64.zip
  - ggml.dll、ggml-base.dll、llama.dll
- Windows x64 CPU：llama-b10621-bin-win-cpu-x64.zip
  - ggml.dll、ggml-base.dll、llama.dll
- Linux x64 CPU：llama-b10621-bin-ubuntu-x64.tar.gz
  - libggml.so、libggml-base.so、libllama.so

按版本存放可以保留旧版动态库；升级代码要求的新版本后，再单独下载并解压对应资产，不覆盖旧版本目录。回滚代码时旧版本目录仍可直接使用。
