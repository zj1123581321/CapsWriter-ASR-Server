# 历史资料归档

本目录保留历史文档、会话记录、研究计划、旧维护账本和迁移报告，供溯源使用。归档内容不自动代表当前服务端的支持范围或操作方式；当前入口见[文档总导航](../README.md)。

- `legacy-client/`：继承的旧客户端文档和完整旧更新日志。旧日志混有早期服务端条目；当前服务端阶段的可核对记录见仓库根目录 [CHANGELOG.md](../../CHANGELOG.md)。其中旧文本拼接算法说明描述的是历史实现，当前算法见 [现行文本拼接说明](../development/algorithms/text-merge.md)。
- `sessions/`：历史交接、进展、设计与评审记录，按原目录层级保存。
- `research/`：当时的研究计划快照。
- `maintainers/`：旧维护账本。
- `reports/`：历史导入报告。

这些资料保留其历史语境；链接或命令中的旧提交、路径和行为描述不应直接作为当前操作指引。
