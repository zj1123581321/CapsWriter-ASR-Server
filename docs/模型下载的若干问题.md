# 模型下载与目录

模型权重不包含在 Git 仓库中。请从上游 [CapsWriter-Offline 模型发布页](https://github.com/HaujetZhao/CapsWriter-Offline/releases/tag/models)下载需要的模型包；该发布页由上游维护。部分模型还会从 Hugging Face 首次联网下载，详情见[模型支持](models.md)。

## 推荐的首次部署模型

首次启动 Paraformer 服务时，下载并准备以下两份模型：

1. Paraformer ASR 模型：`model.onnx` 与 `tokens.txt`。
2. Punct-CT-Transformer 标点模型：`model.onnx` 与 `tokens.json`。Paraformer 没有内建标点能力，服务端会在启动时加载这份辅助模型。

将下载包中的模型目录解压到本仓库 `models/` 下，保留模型目录名和文件层级：

```text
models/
├── Paraformer/
│   └── speech_paraformer-large-vad-punc_asr_nat-zh-cn-16k-common-vocab8404-onnx/
│       ├── model.onnx
│       └── tokens.txt
└── Punct-CT-Transformer/
    └── sherpa-onnx-punct-ct-transformer-zh-en-vocab272727-2024-04-12/
        ├── model.onnx
        └── tokens.json
```

目录名和必要文件名以 [`config_server.py`](../config_server.py) 中的 `ModelPaths` 为准。不要额外多套一层同名目录。

## 其它模型目录

| 引擎/用途 | 模型目录 |
| --- | --- |
| SenseVoice ASR | `models/SenseVoice-Small/Sensevoice-Small-ONNX/` |
| Fun-ASR-Nano | `models/Fun-ASR-Nano/Fun-ASR-Nano-GGUF/` |
| Qwen3-ASR GGUF | `models/Qwen3-ASR/Qwen3-ASR-1.7B/` |
| Qwen3 ForcedAligner | `models/Qwen3-ForcedAligner/Qwen3-ForcedAligner-0.6B/` |
| 标点补足 | `models/Punct-CT-Transformer/sherpa-onnx-punct-ct-transformer-zh-en-vocab272727-2024-04-12/` |

下载包可能同时包含多个引擎文件。第一次部署只需准备选择的 ASR 引擎及其辅助模型；其它模型可以之后再下载。服务启动报错时会列出所选 ASR 引擎缺少的文件和上游下载入口。

## llama.cpp 动态库

只有 GGUF 解码或 ForcedAligner 路径需要 llama.cpp 动态库。当前代码固定使用 `b10621`，动态库需放在 `core/server/engines/llama/bin/b10621/`，不再从 `bin/` 根目录回退加载。资产名和升级步骤见[部署维护与升级](../deploy/README.md)及 [llama.cpp b10621 官方发行页](https://github.com/ggml-org/llama.cpp/releases/tag/b10621)。
