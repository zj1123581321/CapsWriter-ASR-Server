### 里程碑 2：压缩流与子进程回收
- 当前阶段：实现
- 本段结论：FLAC 与 Ogg/Opus 使用每任务 ffmpeg；独立 stdin 写入、按消费许可读取 stdout，并保留最多 500 字节 stderr。现场截断流行为是 ffmpeg 退出码 0、输出 14,976/48,000 个样本，测试锁定为成功退出但明显短流。
- 关键决策与已否决方案：PCM 迭代器每次请求才许可一次 stdout 读取；有限队列预读会削弱调用方节奏控制。
- 下一步唯一动作：完成红验、全套测试与交付报告。
