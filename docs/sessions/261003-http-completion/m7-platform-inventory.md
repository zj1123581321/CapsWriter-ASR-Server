### 0.2 状态三态

「文件缺失 / 权限失败 / 访问未知」在本文严格分开，不合并成一个「没有」：

- **present**：路径存在且可读，字节数已记录。
- **missing**：路径确实不存在（`test -e` 为假，且父目录可读）。
- **no_access**：路径状态无法判定（SSH 不通、权限不足、目录未探到）。`no_access` **不等于** `missing`。

### 0.3 脱敏

公开仓不写 IP、用户名、用户私有绝对路径、Tailscale 主机名、密钥或真实录音内容。原文涉及的机器一律用本文的代号；样本只写时长/格式/字节数等元数据，不写文件名与文本内容。逐字路径与命令见主脑私有报告。

## 6. 下一阶段隔离验收方案（提案，本卡未执行）

以下全部是**提案**，需要授权后才做；本卡没有任何一条被执行过。

### 6.1 隔离运行的基本约束

1. **固定 SHA**：所有机器统一 checkout 到同一个已合并 SHA（当前候选 `5134720` 或其后的合并提交），记录 `git rev-parse HEAD`；不接受「磁盘 HEAD」代替「运行版本」，以 `/health` 的 `git_sha` 为准。
2. **只绑 loopback**：隔离实例一律 `CW_ADDR=127.0.0.1`，端口用与生产不冲突的固定高位端口；HTTP 端口不能为 0（配置显式拒绝），需先选一个空闲端口并记录选取方式。
3. **自有数据目录**：HTTP 路径必须给 `CW_HTTP_DATA_DIR` 一个**稳定绝对路径**，且与生产数据目录完全分离；验收后清理只清自己的目录。
4. **模型只读复用**：从现有部署**只读挂载/复制**已下载的权重，不重新下载、不改生产模型目录；模型路径以 `stat` 的存在性与字节数作为前置判据，缺一即停。
5. **同源素材**：源文件与参考稿必须同源同版本，参考稿与源文件的对应关系要有记录（时长、生成时间、来源），不能拿「大概是同一段」的素材算 CER。

### 6.2 两条字节口径必须分别量

- **HTTP 源字节**：上传文件本身的字节数与采样率/声道/位深，由客户端在发送前记录。
- **WS producer 字节**：客户端实际发出的 `float32` 原始字节（`tobytes()` 长度），由发送方记录，不从服务端日志反推。

两者不等价（解码、重采样、容器剥离都会改字节），必须分别出数，不能只报一个「音频大小」。

### 6.3 质量与耗时口径

- CER：字符级编辑距离 / 参考稿字符数，参考稿需先按书面规则归一化；WER 仅在有分词规则时才报，否则不报。
- 耗时：至少区分「首字延迟」与「整段完成耗时」；重启后首个任务的冷启动值必须与热值分开标注（`B` 已记录两台 Mac 存在冷热差异）。
- 时间戳：沿用 `scripts/_baseline_asr.py` 的两个不变量（单调递增、间隔非均匀）。

### 6.4 平台测试与质量结论的限制

- 每台机器的结论只能覆盖该机的 OS/架构/引擎/后端组合。macOS 两台的 MLX 结果不能外推到 Windows 的 GGUF 或 Linux 的 ONNX。
- 单样本、单参考稿得出的 CER 只能作为**回归基线**，不能作为模型质量结论。
- 非生产环境缺失时，本卡**不声称任何平台已验证**；只有原始状态（探针输出）能支撑「已验证」。
