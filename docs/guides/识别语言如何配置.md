# 识别语言配置

下游请求可通过协议的 `language` 字段选择识别语言。Python SDK 调用 `transcribe_file()` 时传入 `language` 参数；自定义下游按 [协议文档](protocol.md) 在音频消息中设置该字段。

不同引擎支持范围不同。未提供时使用 `auto`，实际处理行为由所选引擎决定。

## 引擎支持范围

### Paraformer

中文专用模型，不支持语言选择，设置后忽略该字段。

### SenseVoice

支持 `auto`（自动检测）、`chinese`、`english`、`cantonese`、`japanese` 和 `korean`。

### FunASR-Nano

支持 `chinese`、`english` 和 `japanese`。

### Qwen3-ASR

支持 `chinese`、`english`、`cantonese`、`japanese`、`korean`、`arabic`、`german`、`french`、`spanish`、`portuguese`、`indonesian`、`italian`、`russian`、`thai`、`vietnamese`、`turkish`、`hindi`、`malay`、`dutch`、`swedish`、`danish`、`finnish`、`polish`、`czech`、`filipino`、`persian`、`greek`、`romanian`、`hungarian` 和 `macedonian`。
