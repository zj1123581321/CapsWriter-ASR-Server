# GPU 与推理后端配置

GPU 设置由服务端配置和所选引擎决定。环境变量在启动服务进程前设置；本页列出当前 `config_server.py` 中的入口，不承诺特定设备上的速度提升。

## 引擎与配置

| 配置 | 默认值 | 作用 |
| --- | --- | --- |
| `CW_ONNX_PROVIDER` | `CPU` | SenseVoice、Fun-ASR-Nano、Qwen GGUF 的 ONNX 编码器/解码器，可选 `CPU`、`CUDA`、`DML`、`TRT` |
| `CW_LLM_USE_GPU` | `0` | Fun-ASR-Nano、Qwen GGUF 解码器是否使用 GPU |
| `CW_VULKAN_FORCE_FP32` | `0` | Fun-ASR-Nano 的 Vulkan 精度选项 |
| `CW_ALIGNER_ONNX_PROVIDER` | `CPU` | ForcedAligner 的 ONNX 后端，和 ASR 后端分开配置 |
| `CW_ALIGNER_LLM_USE_GPU` | `0` | ForcedAligner 的 GGUF 解码器是否使用 GPU |

Paraformer 固定使用 CPU，不受 `CW_ONNX_PROVIDER` 影响。`qwen_asr_mlx` 使用 Apple Silicon 上的 MLX 路径，不通过上述 ONNX/GGUF 开关配置。可用后端还取决于已安装的 ONNX Runtime provider、llama.cpp 动态库、驱动和所选模型；相关配置定义见 [`config_server.py`](../../config_server.py)，引擎选择见[模型支持](../reference/models.md)。

macOS/Linux 可在启动命令前设置变量，例如：

```sh
CW_ONNX_PROVIDER=CUDA CW_LLM_USE_GPU=1 python start_server.py
```

Windows PowerShell 可在当前终端设置：

```powershell
$env:CW_ONNX_PROVIDER = 'DML'
$env:CW_LLM_USE_GPU = '1'
.\.venv\Scripts\python.exe start_server.py
```

启动日志会报告实际选择的推理后端。ONNX provider 与 GGUF GPU 解码是不同设置；ForcedAligner 有独立开关，不会因设置 ASR 变量而自动启用。

## GPU 预加速

`ServerConfig.gpu_boost_enabled` 默认是 `False`。启用后，服务端可在识别任务前后运行 `gpu_boost_cmd` 与 `gpu_unboost_cmd`；默认命令使用 `nvidia-smi`，需要当前平台支持该命令和相应权限。配置位置及命令见 [`config_server.py`](../../config_server.py)。此功能只控制预加速命令，不会替代 ONNX 或 GGUF 的推理后端配置。

首次部署、动态库和更新步骤见[部署维护与升级](../../deploy/README.md)。
